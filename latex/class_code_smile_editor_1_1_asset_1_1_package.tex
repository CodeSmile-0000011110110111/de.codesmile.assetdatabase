\doxysubsubsection{Detailed Description}
Groups import/export functionality for \href{https://docs.unity3d.com/Manual/AssetPackages.html}{\texttt{ .unitypackage files}} (\doxylink{class_code_smile_editor_1_1_asset}{Asset} Packages). 

Does not contain \doxylink{class_code_smile_editor_1_1_asset_1_1_package}{Package} Manager (npm packages) functionality.
